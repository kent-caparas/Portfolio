This is where you get to talk back. Leave a question, an idea, or something you
learned, and it sticks to the wall for everyone to see.
[Go leave one!](/wall)

*The catch:* every note goes through Claude first. It reads your note as plain
text, never as instructions, so I'd still avoid prompt injections. If Claude is
sure a note is fine, it goes up right away. If it's sure it isn't, it's out.
Anything in between waits for me to read it myself. And if the check itself
breaks, the note waits too, because **a broken check should never let a note
through.**

To keep it from getting spammed, you can post up to five notes an hour. You can
also drag the notes around, and everyone sees the same mess, since each note's
spot comes from its id.
